# Bike Sales & Customer Analysis Dashboard

## 📊 Project Overview

This project analyzes bike sales and customer data using Microsoft Excel to identify sales trends, customer behavior, top-performing products, and country-level performance.

The project includes an interactive dashboard with KPIs, charts, slicers, and sales analysis.

## 🎯 Objectives

* Analyze total sales and total profit.
* Track sales performance by month.
* Identify the top 5 products by sales.
* Analyze sales by bike color.
* Compare sales between male and female customers.
* Compare sales performance across countries.
* Provide an interactive dashboard for exploring the data.

## 🛠️ Tools & Technologies

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Analysis
* Data Visualization

## 📈 Dashboard

The dashboard provides an overview of:

* Total Units Sold
* Total Sales
* Total Cost
* Total Profit
* Sales by Month
* Sales by Bike Color
* Top 5 Products by Sales
* Sales by Gender
* Sales by Country

## 💡 Key Insights

The dashboard can be used to identify:

* The highest-selling products.
* The best-performing countries.
* Monthly sales trends.
* Differences in purchasing behavior by gender.
* The contribution of different bike colors to total sales.
